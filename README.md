# 晚点 LatePost 访谈学习导航

个人学习用导航：把晚点的「对话 / 专访 / 口述 / 晚点聊」整理成可搜索清单和学习路径。

**在线阅读：** 打开仓库里的 [`index.html`](./index.html)（也可在 GitHub Pages 开启后直接访问）。

仓库：https://github.com/LiuJiuJie/latepost-interviews

## 里面有什么

| 文件 | 说明 |
| --- | --- |
| `index.html` | 可视化学习页：官方入口、主题路径、文字访谈卡片、晚点聊目录（可搜索/筛选） |
| `data/latetalk.csv` | 《晚点聊 LateTalk》目录（本仓库收录 127 期，官方全集 180 期） |
| `data/written.csv` | 精选文字访谈 |

## 怎么用

1. 先走 `index.html` 里的学习路径（入门 / 大模型 / Agent / 具身 / 创始人 / 出海）。
2. 用搜索框按嘉宾、公司、主题检索。
3. 「打开」跳到 [podcast.latepost.com](https://podcast.latepost.com/) 官方节目页。

完整官方归档：https://podcast.latepost.com/episodes

## 开启 GitHub Pages（可选）

1. 打开仓库 **Settings → Pages**
2. Source 选 **Deploy from a branch**
3. Branch 选 `main`，文件夹选 `/ (root)`
4. 保存后访问：`https://liujiujie.github.io/latepost-interviews/`

## 说明

- 晚点自 2019 年起还有大量非访谈报道，本仓库只收录对话类内容。
- 早期少量期数在官方目录可能跳号；缺期可用 `https://podcast.latepost.com/{period}` 打开。
- 微信文章链接可能失效，请用标题在公众号《晚点 LatePost》《晚点对话》内搜索。
